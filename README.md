* `v4` / `release`: Used by very old Rainmeter versions
* `status.json`: Used by Rainmeter <= 4.5.27
* `status-v4.json`: Used by Rainmeter >= 4.5.28 on systems that are **not** compatible with Rainmeter 5.0 requirements
* `status-v5-capable.json`: Used by Rainmeter >= 4.5.28 on systems that are compatible with Rainmeter 5.0 requirements
* `v5.ini`: Used by Rainmeter >= 5.0
